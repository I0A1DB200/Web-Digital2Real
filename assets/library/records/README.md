# Reusable asset records

Future `AST-xxxxxx.yaml` records describe reusable D2R production assets. They may reference external technical or visual evidence with:

```yaml
source_ids: []
```

A source relationship does not transfer copyright, license, transformation permission, production approval, or evidentiary authority. External imagery is `ASSET_REFERENCE` by default. Experience-local assets remain owned by their Experience packages.
