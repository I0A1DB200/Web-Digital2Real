# Digital2Real Content

This directory owns authored Digital2Real knowledge and learning material.

## Responsibilities

```text
content/
├── notebooks/
├── capabilities/
├── experiences/
└── assessments/
```

- [`notebooks/`](notebooks/README.md) owns reusable technical knowledge.
- `capabilities/` will own concrete Industrial Capability definitions after their approved migration.
- [`experiences/`](experiences/README.md) owns Experience Briefs, Experiences, and authoring assets.
- [`assessments/`](assessments/README.md) owns future approved Assessment content.

Content is independent from the software that processes or presents it. It MUST NOT contain application runtime logic, UI components, generated browser packages, or architecture governance.

Ownership is governed by [ADR-0001](../docs/03-governance/decisions/ADR-0001-content-ownership.md).
