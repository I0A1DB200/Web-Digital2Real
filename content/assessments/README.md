# Assessment Content

This directory is the approved ownership boundary for future Digital2Real Assessment content.

No Assessment content has been approved or migrated.

## Allowed content

- approved Assessment specifications;
- Assessment scenarios and evidence definitions;
- traceability to Capability versions and assessment criteria.

## Prohibited content

- scoring or validation runtime implementations;
- learner profiles or certificates;
- UI components;
- speculative Assessment examples;
- generated results or session records.

Assessment requirements are governed by [D2R-004 — Assessment Standard](../../docs/02-standards/D2R-004-assessment-standard.md). New content requires separate approval.
