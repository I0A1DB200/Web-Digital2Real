# EE-0022 media source

These seven assets are a coherent visual set for a PROFINET commissioning case. The supplied Siemens PRONETA Basic V3.2 documentation and reference images were used as visual guidance for the device table, topology, online identity comparison and name-assignment workflow; the resulting software panels are original instructional simulations, not copied vendor screenshots.

- `01-cover.png` — automation cabinet with S7-1500, SCALANCE and PROFINET line hardware.
- `02-topology-name-mismatch.png` — clearly simulated topology view with one identity mismatch.
- `03-device-identity.png` — field-style ET 200SP status evidence with link present and BF diagnostic active.
- `04-online-name-check.png` — clearly simulated expected-versus-discovered identity comparison.
- `05-proneta-commissioning.png` — clearly simulated PRONETA commissioning view.
- `06-hardware-download.png` — clearly simulated TIA Portal hardware download view.
- `07-recovery-verified.png` — clearly simulated recovery view with six available lines and a stable trend.

The hardware vocabulary follows the reference installation: Siemens SIMATIC S7-1500 controller, SCALANCE industrial switch, ET 200SP remote I/O heads, PROFINET device names and IP identity fields. The software views are instructional simulations, not vendor screenshots or live measurements. No human figures are used.
