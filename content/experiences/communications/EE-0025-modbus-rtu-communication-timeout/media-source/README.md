# Media source — EE-0025

El subdirectorio `EE-0025_assets/` conserva los seis SVG recibidos para la revisión de assets y el README incluido en el ZIP original. Son borradores editables en inglés: no son capturas verificadas de TIA Portal ni fotografías finales de hardware.

Para el runtime se generaron seis PNG rasterizados de 1200 × 675 px a partir de esos SVG. Las plantillas de parámetros incluyen `TO BE VERIFIED` deliberadamente; no deben sustituirse por valores inventados antes de cerrar la revisión técnica.

La cadena visual sigue la secuencia de ENV-003: contexto de instalación, síntoma de diagnóstico, frontera/topología RS-485, comparación de cliente-servidor y verificación de recuperación.
