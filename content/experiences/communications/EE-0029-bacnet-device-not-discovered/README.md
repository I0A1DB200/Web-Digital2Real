# EE-0029 — Dispositivo BACnet no descubierto

Experience bilingüe de diagnóstico de descubrimiento BACnet/IP entre subredes. El caso separa disponibilidad local, direccionamiento, enrutamiento IP y distribución de broadcast BACnet antes de restaurar el mecanismo compatible.

La representación visual está disponible con seis assets aprobados, uno por evidencia, y una portada asociada a `ART-001`. Las copias de ejecución están en `assets/` y los originales suministrados se conservan en `media-source/EE-0029_assets/`.

La causa raíz se mantiene neutral respecto al fabricante: falta un mecanismo BBMD o Foreign Device compatible con la arquitectura autorizada. Las imágenes son recreaciones didácticas y fijan sus IP, puerto e instancia para este escenario; esos valores no se presentan como parámetros universales de una instalación real.
