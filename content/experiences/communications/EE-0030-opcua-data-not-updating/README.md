# EE-0030 — Datos OPC UA sin actualizar

Experience bilingüe de diagnóstico OPC UA para separar una sesión conectada de una suscripción o monitored item que no entrega cambios del proceso.

La representación visual está planificada. Se han definido siete requisitos de evidencia, pero todavía no se han integrado imágenes aprobadas; `assets/` permanece vacío y `media-source/` solo conserva la especificación editorial.

La causa raíz se mantiene neutral respecto al fabricante: una configuración incorrecta del monitored item o de la suscripción impide las notificaciones de cambio esperadas. No se fijan endpoints, NodeIds, intervalos ni valores de hardware que no estén documentados.
