# Registered browser assets

This directory contains the seven registered PNG assets. Packaging consumes these files without changing their bytes. Registration does not imply presentation or technical validation of every depicted value.

ART-001 is cover; ART-002 and ART-005 accompany acquired evidence and subsequent stage context; ART-007 illustrates final validation and Debrief. ART-003, ART-004 and ART-006 remain registered but intentionally unpresented pending technical/media clarification. See ../ASSET-REQUIREMENTS.md for discrepancies and limitations. No binaries were edited or renamed for the remap.
