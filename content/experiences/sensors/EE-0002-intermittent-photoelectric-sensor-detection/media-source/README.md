# Media source

No separate editable source masters were supplied. Packaging consumes the PNG files within [`../assets/`](../assets/); there is no parallel media/ collection to synchronize.

The effective images have the limitations documented in [`../ASSET-REQUIREMENTS.md`](../ASSET-REQUIREMENTS.md). ART-003, ART-004 and ART-006 remain registered but intentionally unpresented pending technical/media clarification. This documentation does not certify their measurements or resolve them by choosing a new binary authority.
