# Digital2Real Governance

## Responsibility

This directory governs:

- architectural evolution;
- document and model versioning;
- review and approval;
- ownership;
- compatibility;
- formal architecture decisions.

## Canonical document

[D2R-008 — Architecture Governance](D2R-008-architecture-governance.md)

The [Engineering Director Playbook](ENGINEERING-DIRECTOR-PLAYBOOK.md) is the operational governance authority for classifying, implementing, validating, and reporting D2R work. D2R-008 retains authority over architectural evolution, approvals, compatibility, and decisions.

The [Constitution](../Constitution.md), [Development Workflow](../DEVELOPMENT_WORKFLOW.md), RFCs, and Project Status retain their distinct responsibilities.

Architecture decisions belong in [`decisions/`](decisions/README.md). No historical ADRs were invented during baseline creation.
