## RULES

The asset must be driven by engineering information need.

Do not over-specify decorative details.

Do not encode unsupported technical facts.

If an existing approved library asset satisfies the need, recommend
reuse instead of creating a new asset.

## ACCEPTANCE

The future asset passes only when pixels, technical context, semantic
role, and disclosure timing all match this specification.
