# Codex Contract — Register Source

**Mode:** INSPECT → NORMALIZE → REGISTER → VALIDATE

Read repository governance and `knowledge/source-library/README.md`. Inspect existing records before creating one.

1. Establish the source's canonical identity and check duplicates.
2. Record exact product, variant, revision, software and protocol applicability only when supported.
3. Record provenance, availability, locations and rights independently.
4. Use unknown or empty values when repository evidence is insufficient; never invent equivalence between language variants.
5. Register external imagery as `ASSET_REFERENCE` unless separately approved as a D2R asset.
6. Never store credentials or assume authenticated access can be automated.
7. Never self-approve. Codex-created records remain below `approved` until explicit Architect or Engineering review.
8. Update the master index without duplicating the full record and run validator/tests.

Do not download, publish, or migrate binaries unless the task explicitly authorizes it.
