# Codex Contract — Resolve Source

**Mode:** QUESTION → APPLICABILITY → AUTHORITY → RESULT

1. Define the technical question and required precision.
2. Search Notebook first, then reviewed D2R references, then the Source Library.
3. Filter candidates by exact applicability, review state, authority, availability and rights.
4. Prefer protocol-neutral authority for protocol claims and applicable manufacturer authority for exact product claims.
5. Expose uncertainty, conflicts, stale locations and unsupported extrapolation.
6. Use broader external research only when authorized; register useful results before governed reuse.

Resolution does not approve a source, transfer rights, or turn an external image into a production asset.
